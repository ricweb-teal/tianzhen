# 天真汉堡 · 个人网站

纯静态站点，无需构建。

## 页面
- index.html 首页
- works.html 作品
- about.html 关于
- contact.html 联系

## 部署到 GitHub Pages
1. 新建仓库（Public）
2. 上传本目录全部文件（或用 git push）
3. Settings → Pages → Source 选 main 分支 / root
4. 访问 https://你的用户名.github.io/仓库名/

## 本地预览
直接用浏览器打开 index.html 即可。
